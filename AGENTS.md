# Portfolio project instructions

This is Vedsai V's job-application portfolio.

## Product goals
- Keep the interface calm, minimal, professional, and easy to scan.
- Use a single centered content column.
- Give every major section generous visual space.
- Preserve direct anchor navigation between sections.
- Prioritize evidence, projects, and measurable outcomes over decoration.

## Design constraints
- No split-screen or two-column hero.
- No bento grid, large metric cards, gradients, glassmorphism, 3D effects, parallax, or continuous animation.
- Use one muted accent colour and neutral backgrounds.
- Preserve keyboard focus and reduced-motion support.
- Keep the custom data-point cursor subtle and desktop-only.

## Technical constraints
- Use plain HTML, CSS, and JavaScript.
- Do not add dependencies, frameworks, or a build step unless explicitly requested.
- Preserve GitHub Pages compatibility.
- Keep visible content in `index.html` and `resume.pdf` at the repository root.

## Content constraints
Do not invent experience, achievements, metrics, project links, certifications, or skills. Use only details supplied by Vedsai.
