Duck Duck Defer

Award-winning

An AI-integrated Android app that manages deferred university exams for students, faculty, and administrators.

  • Kotlin
  • Jetpack Compose
  • Firebase
  • Gemini API
My role
Frontend Software Developer / Business Analyst
Team
Five-member Agile/Scrum team

Problem

Deferred exams relied on manual scheduling and scattered information, which led to booking conflicts, limited room capacity, communication delays, and repetitive administrative work. The goal was one system for students, faculty, administrators, and proctoring.

System features, built by the team

  • Role-based dashboards with their own navigation, data, quick actions, and permissions.
  • Exam booking by date, room, and time slot, with seat tracking, conflict checks, and transactional seat updates.
  • Exam lifecycle: Booked, Fee Paid, Checked In, Exam Finished, Dropped Off, Faculty Received.
  • DuckBot, a Gemini-powered assistant that answers policy questions and helps with supported actions. The developer guide documents approximately 28 executable commands and 14 navigable screens.
  • Real-time messaging and notifications through Firestore listeners and Firebase Cloud Messaging.
  • QR check-in and proctoring, including assigned sessions and incident reporting.
  • Access control in the application design: Firebase Authentication, admin approval, server-side role checks, biometric login, and encrypted local credentials.
  • Gamification, accessibility settings, and a home-screen booking widget.

Architecture flow

MVVM data flow: Compose UI, ViewModel, Repository or Firebase services, Firestore or Cloud Functions, real-time state, updated UI.

DuckBot action pipeline:

  1. A user types a request in the chat.
  2. The ViewModel adds role and policy context.
  3. The request goes to the Gemini API.
  4. Structured action markers are parsed from the response.
  5. The action registry checks what the role supports.
  6. A wizard collects any missing inputs.
  7. The secure action service calls Cloud Functions with authentication.
  8. Server-side code validates permissions and performs the operation.
  9. The result returns to the conversation.

An AI-generated request is not treated as authorization: sensitive operations go through protected backend endpoints.

Testing

JUnit, AndroidX Test with Espresso, Compose UI Test, and ArchUnit. The team tracked and fixed defects iteratively across notification navigation, booking forms, account management, and availability.

My contributions

I contributed to requirements-oriented development, role-based UI and workflows, modular application components, frontend, backend, and database integration, AI and Firebase integration, testing, debugging, and documentation.

IknowServiceAI

A full-stack AI service request agent for classification, knowledge retrieval, and recommendations, with human-in-the-loop approvals.

  • Python
  • FastAPI
  • React
  • PostgreSQL
  • Gemini API
My role
Full-stack development, Gemini API integration, and testing

Problem

Service requests are often written in free-form language and need manual interpretation, classification, information lookup, and decisions, which is repetitive and hard to standardize.

Features

  • AI-assisted classification of service requests with the Gemini API.
  • Knowledge retrieval relevant to each request, and intelligent recommendations built on it.
  • React frontend connected to Python and FastAPI REST API microservices.
  • PostgreSQL and SQL for relational persistence.
  • Responsible AI workflow: AI governance, privacy safeguards, human-in-the-loop approvals, and audit logging.

Request flow

  1. A user submits a request in the React interface.
  2. The frontend sends it to a FastAPI service.
  3. Gemini supports interpretation and classification.
  4. The system retrieves relevant knowledge and supports recommendations.
  5. Where applicable, humans review or approve AI-assisted actions.
  6. PostgreSQL stores application data, and audit logging captures activity.
  7. The backend returns the result for the frontend to display.

This is a conceptual view of the documented features, not an endpoint-by-endpoint trace.

Testing

Automated unit and integration tests with pytest, plus debugging of frontend and backend integrations. Services are containerized with Docker.

My contributions

I developed the full-stack application with React, FastAPI, and PostgreSQL, integrated Gemini for classification, knowledge retrieval, and recommendations, incorporated AI governance, privacy safeguards, approvals, and audit logging, implemented pytest unit and integration tests, and containerized the services with Docker.

Testing
